name=Universal XY Converter
description=Universal coordinate converter supporting all QGIS CRS (200+ systems) with native BFTM support for Burkina Faso. Convert between any CRS: WGS84, UTM zones 1-60, Adindan, Clarke 1880, NAD83, ETRS89, GDA2020, and custom PROJ strings. Features: single conversion, batch CSV processing, interactive map picking, support for DD, DMS (with French notations O/E/N/S), and meters.

about=Universal XY Converter is a powerful QGIS plugin for coordinate conversion between any Coordinate Reference Systems (CRS) available in QGIS, with native support for BFTM (Burkina Faso Transverse Mercator). Features: single conversion, batch CSV processing, interactive map picking, support for DD, DMS (with French notations O for Ouest, E for Est, N for Nord, S for Sud), and meters format. Now supports Clarke 1880 and Adindan in degrees and UTM zones (all zones 1-60 N/S) with region-specific parameters: West Africa (-118,-14,218) and Cameroon (-166,-15,204). Multilingual support: French/English automatically based on QGIS language.
